6. CAJA CHICA — LÓGICA CLARA
==================================================

Caja Chica es un fondo fijo.

Ejemplo:

Monto base de Caja Chica: S/ 100.00

Ese monto debe conservarse y no debe considerarse venta ni ingreso.

Debe registrar:

- Monto base.
- Dinero contado.
- Diferencia.
- Estado de la diferencia.
- Justificación.
- Usuario.
- Sede.
- Fecha.
- Hora.

La fórmula es:

Diferencia = Dinero contado - Monto base

Interpretación:

1. Si la diferencia es igual a 0:

- Mostrar estado: “Caja correcta”.
- No existe sobrante ni faltante.
- El monto base permanece completo.

Ejemplo:

Monto base: S/ 100.00
Dinero contado: S/ 100.00
Diferencia: S/ 0.00

Resultado:

- La Caja Chica conserva S/ 100.00.
- No falta dinero.
- No sobra dinero.
- No se registra ganancia por Caja Chica.

2. Si la diferencia es mayor que 0:

- Mostrar estado: “Sobrante”.
- El monto base debe conservarse.
- Solo el dinero que excede el monto base debe mostrarse como sobrante.
- El sobrante debe registrarse por separado.
- No debe aumentar automáticamente el monto base.
- El sobrante puede incluirse en el resumen como ingreso adicional o dinero por rendir, según corresponda.
- Debe registrar usuario, sede, fecha y hora.

Ejemplo:

Monto base: S/ 100.00
Dinero contado: S/ 130.00
Sobrante: S/ 30.00

Resultado:

- S/ 100.00 permanecen como Caja Chica.
- S/ 30.00 se registran como sobrante.
- No duplicar ese sobrante como ingreso.

3. Si la diferencia es menor que 0:

- Mostrar estado: “Faltante”.
- Mostrar claramente cuánto dinero falta.
- Pedir una justificación obligatoria.
- No registrar el faltante como ganancia o ingreso.
- Guardar usuario, sede, fecha y hora.

Ejemplo:

Monto base: S/ 100.00
Dinero contado: S/ 75.00
Faltante: S/ 25.00

Resultado:

- Mostrar que faltan S/ 25.00.
- Exigir justificación.
- Mantener trazabilidad.

IMPORTANTE:

- Caja Chica nunca se suma al total vendido.
- Caja Chica nunca se considera ingreso.
- El monto base debe mantenerse separado.
- El sobrante debe mostrarse por separado.
- El faltante debe mostrarse por separado.
- No duplicar el sobrante como ingreso.
- No modificar el monto base automáticamente.

El resumen debe mostrar:

- Monto base.
- Dinero contado.
- Sobrante.
- Faltante.
- Diferencia.
- Estado.
- Justificación.
